## 🛠️ 採用ロジック（スペック管理）

一般的な一律の計算式ではなく、筋肉の動員特性と先行研究に基づき、種目ごとに最も高精度とされる推定式を出し分けています。

### 1. ベンチプレス
- **採用式**: Brzycki（ブリジッキ）式
- **計算式**: `1RM = 重量 × 36 ÷ (37 − 回数)`
- **特徴**: 高レップ（回数が多い）時にも過大評価されにくく、上半身のプレス系種目において高い相関を示すため採用。

### 2. スクワット / デッドリフト
- **採用式**: 修正 Epley（エプリー）式
- **計算式**: `1RM = 重量 × (1 + (回数 − 1) ÷ 30)`
- **特徴**: 下半身の多関節種目において、レップ数が重なった際の神経系・筋持久力のタレを補正し、実際の1RMに最も近くなるよう係数を調整。
